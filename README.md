# Is it a "hybrid swarm"? Opportunities for more informative terminology in conservation genomics
R scripts posted here were used for the PubMed journal search and in creating plots. The published paper is available here: https://doi.org/10.1002/ece3.74515 and the raw data files from this paper are also available on DataDryad here: https://doi.org/10.5061/dryad.w3r228189 

## Description of scripts
```hybridswarm_plotting.R``` is the script used to create figures 2, 3, and 4 in the manuscript. 

```hybrid_swarm_pubmed.R``` is the script used to perform the PubMed search for gathering papers related to the term "hybrid swarm".
